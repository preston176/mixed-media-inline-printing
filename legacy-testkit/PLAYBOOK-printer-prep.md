# Printer Prep & Power-On — Operator Playbook

**Scope:** physically prepare the Sharp BP-70C65 and power it on. That's all —
nothing on the PC. When every box is ticked, hand off to the testkit operator.

Tick each box that passes. If something's wrong (error, jam, wrong paper), fix it
before continuing.

> Panel menu labels and tab-loading orientation vary by model/firmware. Follow the
> **label inside the tray** and the on-screen prompts if they differ from the wording here.

---

## 1 · Power on

- [ ] Power cable connected; main power switch **on**
- [ ] Press the operation (power) button; if the panel is dark, wake it
- [ ] Let warm-up finish
- [ ] Panel shows **Ready** with no error or jam message

---

## 2 · Load Tray 1 — 5-cut tab stock

- [ ] Slide Tray 1 out
- [ ] Fan the tab stock so sheets don't stick
- [ ] Load a **full bank in tab order** (tab position 1 first), tabs aligned to the
      edge shown on the in-tray label — don't load it upside down
- [ ] Slide the paper guides snug against the stack
- [ ] Close the tray
- [ ] At the panel, set **Tray 1 → paper type = Tab Paper**, size = your stock size

> Note: Sharp often expects tab stock in the **bypass** tray. If the machine won't
> accept tab stock in Tray 1, load it in the tray it allows and tell the operator
> which one: `________`.

---

## 3 · Load Tray 2 — letter plain

- [ ] Slide Tray 2 out
- [ ] Load **letter plain** paper; guides snug against the stack
- [ ] Close the tray
- [ ] At the panel, set **Tray 2 → paper type = Plain**, size = **Letter**

---

## 4 · Final checks

- [ ] No low-toner or out-of-paper warnings
- [ ] No jams; all covers and trays closed
- [ ] Panel shows **Ready**
